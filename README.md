# 왕실 등록 시스템

존함을 입력하면 최효은인지 아닌지에 따라 반응이 갈리는 병맛 오프닝.

```bash
npm run dev      # 개발 서버
npm run build    # 배포용 빌드 (dist/)
```

## 스택

React 19 · TypeScript · Vite 8 · Tailwind CSS v4 · **Motion** · Zustand · canvas-confetti

---

## 지금 만들어진 것

1. **처음 화면** — 안녕하세요(글자별 등장) → 공주님(무지개) → 👑
2. **존함 입력** — 왕실 DB 조회(99%에서 멈추는 로딩바) → 확인 팝업(아니요 버튼은 도망감)
3. **이름 분기**

| | **최효은** | 그 외 |
|---|---|---|
| 확인 팝업 | 정말 **최효은 공주님**이 맞으십니까? | 정말 OOO **님... 맞으십니까?** |
| 아이콘 | 👑 | 🤨 |
| 대사 | 공주님 안녕하십니까 → 환영합니다 → **사랑합니다** | **{이름}...?** → 너 누군데? → ... → **나가라** |
| 사진 | `환영합니다*.jpg` 5장 (금테) | `너 누군데*.jpg` 5장 (채도 낮춤) |
| 이펙트 | 왕관비 · 폭죽 · 하트폭탄 · 연속폭죽 | 글리치 · 화면흔들기 · 빨간번쩍 |
| 버튼 | **입 장 하 기** → 본편으로 | **냅다 꺼지기** → 입력 화면으로 되돌아감 |

사진은 대사가 진행될수록 화면 가장자리에 한 장씩 깔려서, 마지막 대사쯤 5장이 다 나옵니다.

## 고칠 곳

| 뭘 | 어디 |
|---|---|
| 공주님 이름 | [src/game/config.ts](src/game/config.ts) 의 `PRINCESS` |
| 환영 대사 | [NameInput.tsx](src/screens/NameInput.tsx) 의 `WELCOME_PRINCESS` / `WELCOME_STRANGER` |
| 사진 목록 | 같은 파일의 `IMG_PRINCESS` / `IMG_STRANGER` |
| 사진 위치 | 같은 파일의 `SPOTS` |
| 입력 검증 문구 | 같은 파일의 `validate()` |

대사 안의 `{이름}` 은 입력한 존함으로 치환됩니다.

## 아직 안 한 것

- **본편** — 입장하면 자리표시 화면만 뜹니다 ([App.tsx](src/App.tsx))
- BGM — `public/Springtime.mp3` 는 아직 안 씀

오프닝 팡파레는 브라우저 자동재생 정책 때문에 첫 터치 전까지 안 울립니다.

## 주의

`Stage.tsx` 에서 이펙트를 재생하려고 **`key` 를 바꾸면 안 됩니다.** key가 바뀌면 그 아래 전체가
리마운트돼서 게임이 처음으로 되돌아갑니다. 줌 펀치가 이 문제를 일으켰고 지금은 `useAnimate` 로
명령형 재생하도록 바꿔놨습니다.
